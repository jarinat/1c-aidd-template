# YAxUnit — справочник API и шаблоны кода

Этот файл содержит полный справочник API фреймворка YAxUnit, шаблоны кода
и примеры для генерации тестов.

Важно: примеры ниже могут содержать комментарии для пояснения API. При
генерации проектного кода не переноси эти комментарии и не добавляй
AAA-маркеры `Подготовка`, `Действие`, `Проверка`, если пользователь явно не
попросил об этом.

Документация: https://bia-technologies.github.io/yaxunit/

## 1. Регистрация тестов

Все тесты регистрируются через модуль `ЮТТесты` в обязательной процедуре
`ИсполняемыеСценарии`.

### Основные методы

```1c
// Добавление тестов
ЮТТесты.ДобавитьТест("ИмяМетода")                         // Во всех контекстах
ЮТТесты.ДобавитьТест("ИмяМетода", "Представление")        // С отображаемым именем
ЮТТесты.ДобавитьТест("ИмяМетода", , , "Сервер")           // Только на сервере
ЮТТесты.ДобавитьСерверныйТест("ИмяМетода")                // Только на сервере
ЮТТесты.ДобавитьКлиентскийТест("ИмяМетода")               // Только на клиенте

// Группировка в наборы
ЮТТесты.ДобавитьТестовыйНабор("ИмяНабора")

// Параметризованные тесты
ЮТТесты.ДобавитьТест("Сложение")
    .СПараметрами(2, 3, 5)
    .СПараметрами(0, 0, 0)
    .СПараметрами(-1, 1, 0)

// Параметры в конкретном контексте
.СПараметрамиНаСервере(Параметр1, Параметр2)
.СПараметрамиНаКлиенте(Параметр1, Параметр2)
```

### Настройки тестов

```1c
// Выполнение в транзакции (данные откатятся)
.ВТранзакции()
.ВТранзакции(Ложь)  // Явное отключение

// Автоматическое удаление тестовых данных
.УдалениеТестовыхДанных()

// Обработчики событий
.Перед("ИмяМетодаПодготовки")
.После("ИмяМетодаОчистки")

// Теги
.Тег("Критичный")
ЮТТесты.ДобавитьТестовыйНабор("Набор", "Тег1,Тег2")

// Представление
.Представление("Понятное имя теста")
```

### Полный пример регистрации

```1c
Процедура ИсполняемыеСценарии() Экспорт

    ЮТТесты
        // Настройки для всего модуля
        .ВТранзакции()
        .Перед("ПодготовкаДанных")
        .После("ОчисткаДанных")

        .ДобавитьТестовыйНабор("Расчёт суммы документа")
            .ДобавитьСерверныйТест("РасчётСуммыСОднойСтрокой")
            .ДобавитьСерверныйТест("РасчётСуммыСНесколькимиСтроками")
            .ДобавитьСерверныйТест("РасчётСуммыПустогоДокумента")

        .ДобавитьТестовыйНабор("Проведение документа")
            .ДобавитьСерверныйТест("ПроведениеДокумента_ФормируетДвижения")
            .ДобавитьСерверныйТест("ПроведениеБезДаты_ВыбрасываетИсключение")
    ;

КонецПроцедуры
```

## 2. Утверждения

Точка входа: `ЮТест.ОжидаетЧто(ПроверяемоеЗначение, ОписаниеПроверки)`.
Возвращает модуль `ЮТУтверждения` с текучим интерфейсом.

**Важно**: всегда используй `ЮТест.ОжидаетЧто()`, а не `ЮТУтверждения.Что()`.

### Сравнение значений

```1c
ЮТест.ОжидаетЧто(Значение)
    .Равно(ОжидаемоеЗначение)
    .НеРавно(Значение)
    .Больше(Значение)
    .БольшеИлиРавно(Значение)
    .Меньше(Значение)
    .МеньшеИлиРавно(Значение)
    .ЭтоНеопределено()
    .ЭтоНеНеопределено()
    .ЭтоNull()
    .ЭтоНеNull()
    .ЭтоИстина()
    .ЭтоНеИстина()
    .ЭтоЛожь()
    .ЭтоНеЛожь()
    .ВСписке(Массив)
```

Особенность: сравнение типизированное. `1` НЕ равно `Истина` в YAxUnit,
хотя в 1С `1 = Истина` это `Истина`. Структуры и массивы сравниваются
по значению (рекурсивно).

### Проверка заполненности

```1c
.Заполнено()
.НеЗаполнено()
.Существует()       // Не Null и не Неопределено
.НеСуществует()
```

### Проверка строк

```1c
.Содержит("подстрока")
.НеСодержит("подстрока")
.НачинаетсяС("префикс")
.ЗаканчиваетсяНа("суффикс")
.ИмеетДлину(10)
.ИмеетДлинуБольше(5)
.ИмеетДлинуМеньше(20)
.НеИмеетДлину(0)
.СодержитСтрокуПоШаблону("^[а-яА-Я]+$")  // Регулярные выражения
.НеСодержитСтрокуПоШаблону("\d")
```

### Проверка типа

```1c
.ИмеетТип("Число")
.ИмеетТип("Строка, Число")           // Любой из перечисленных
.ИмеетТип(Тип("Строка"))
.ИмеетТип(Новый ОписаниеТипов("Строка, Число"))
.НеИмеетТип("Массив")
```

### Проверка интервалов

```1c
.МеждуВключаяГраницы(0, 100)
.МеждуИсключаяГраницы(0, 100)
.МеждуВключаяНачалоГраницы(НачалоДня, НачалоСледующегоДня)
.МеждуВключаяОкончаниеГраницы(0, 100)
```

### Проверка свойств (позиционирование)

```1c
// Проверка свойства объекта
ЮТест.ОжидаетЧто(Документ)
    .Свойство("Номер").Заполнено()
    .Свойство("Дата").Заполнено()
    .Свойство("Поставщик").Равно(Поставщик)
    .Свойство("Товары").ИмеетДлину(2)
    .Свойство("Товары[0].Товар").Равно(Товар1)
    .Свойство("Товары[0].Количество").Больше(0)
    .Свойство("Товары[-1].Сумма").Равно(200)  // Последний элемент

// Проверка наличия свойства
.ИмеетСвойство("ИмяСвойства")
.НеИмеетСвойства("ИмяСвойства")
.ИмеетСвойстваРавные(Новый Структура("Свойство1, Свойство2", Значение1, Значение2))

// Возврат к объекту после позиционирования
.Объект()  // Вернуться к объекту из ОжидаетЧто
```

**Важно**: `.Свойство()` и `.Элемент()` всегда вычисляют путь от объекта,
указанного в `ОжидаетЧто()`. Они НЕ вкладываются:

```1c
// НЕПРАВИЛЬНО (не работает как ожидается):
.Свойство("Реквизит")
    .Свойство("ВложенныйРеквизит").Равно(1)  // Ищет "ВложенныйРеквизит" у корня!

// ПРАВИЛЬНО:
.Свойство("Реквизит.ВложенныйРеквизит").Равно(1)
```

### Проверка коллекций

```1c
ЮТест.ОжидаетЧто(Массив)
    .ИмеетДлину(3)
    .ИмеетДлинуБольше(2)
    .Содержит(1)                         // Конкретное значение
    .Содержит(ЮТест.Предикат()           // По предикату
        .ИмеетТип("Число").Больше(2))
    .НеСодержит(0)
    .КаждыйЭлементСодержитСвойство("Имя")
    .КаждыйЭлементСодержитСвойствоСоЗначением("Статус", 1)
    .ЛюбойЭлементСодержитСвойство("Комментарий")
    .ЛюбойЭлементСодержитСвойствоСоЗначением("Тип", "Основной")
    .КаждыйЭлементСоответствуетПредикату(ЮТест.Предикат()
        .ИмеетТип("Число").НеРавно(0))
    .ЛюбойЭлементСоответствуетПредикату(ЮТест.Предикат()
        .Больше(10))
```

### Проверка выполнения метода (исключения)

```1c
// Проверка, что метод выбрасывает исключение
ЮТест.ОжидаетЧто(ВладелецМетода)
    .Метод("ИмяМетода")                   // Имя метода строкой!
    .Параметр(Параметр1)                  // Параметры вызова
    .Параметр(Параметр2)
    .ВыбрасываетИсключение("Текст ошибки")  // Текст обязателен!

// Проверка, что метод НЕ выбрасывает исключение
ЮТест.ОжидаетЧто(ВладелецМетода)
    .Метод("ИмяМетода").Параметр(Значение)
    .НеВыбрасываетИсключение()

// Выполнение в транзакции (третий параметр = Истина)
.ВыбрасываетИсключение("Текст", , Истина)
.НеВыбрасываетИсключение("Текст", , Истина)
```

**Критически важно**: метод указывается СТРОКОЙ, явный вызов ЗАПРЕЩЁН:
```1c
// ПРАВИЛЬНО:
ЮТест.ОжидаетЧто(Документ).Метод("Записать").Параметр(РежимЗаписиДокумента.Проведение)
    .ВыбрасываетИсключение("Дата");

// НЕПРАВИЛЬНО (метод вызовется ДО проверки):
ЮТест.ОжидаетЧто(Документ).Метод(Документ.Записать(РежимЗаписиДокумента.Проведение))
```

### Проверка предикатом

```1c
ЮТест.ОжидаетЧто(Объект)
    .СоответствуетПредикату(ЮТест.Предикат()
        .Заполнено()
        .ИмеетТип("Структура")
        .Реквизит("Число").Больше(0))
```

## 3. Тестовые данные

Точка входа: `ЮТест.Данные()`. Возвращает модуль `ЮТТестовыеДанные`.

### Создание объектов ИБ

```1c
// Создание пустышек (минимально заполненных объектов)
Ссылка = ЮТест.Данные().СоздатьЭлемент("Справочники.Номенклатура");
Ссылка = ЮТест.Данные().СоздатьГруппу("Справочники.Номенклатура");
Ссылка = ЮТест.Данные().СоздатьДокумент("Документы.ПриходТовара");

// Конструктор объекта — создание с нужными реквизитами
Ссылка = ЮТест.Данные().КонструкторОбъекта("Справочники.Номенклатура")
    .Установить("Наименование", "Тестовый товар")
    .Установить("Артикул", "АРТ-001")
    .Установить("ЕдиницаИзмерения", ЕдиницаИзмерения)
    .ДобавитьСтроку("Характеристики")
        .Установить("Наименование", "Цвет")
        .Установить("Значение", "Красный")
    .Записать();

// Конструктор документа
Ссылка = ЮТест.Данные().КонструкторОбъекта("Документы.ПриходТовара")
    .Установить("Дата", ТекущаяДата())
    .Установить("Поставщик", Поставщик)
    .Установить("Склад", Склад)
    .ДобавитьСтроку("Товары")
        .Установить("Товар", Товар)
        .Установить("Количество", 10)
        .Установить("Цена", 100)
    .Провести();  // Или .Записать()

// Изменение реквизитов существующего объекта
ЮТест.Данные().УстановитьЗначениеРеквизита(Ссылка, "Наименование", "Новое");
ЮТест.Данные().УстановитьЗначенияРеквизитов(Ссылка,
    Новый Структура("Наименование, Код", "Новое", "001"));
```

### Генерация случайных данных

```1c
ЮТест.Данные().СлучайноеЧисло(1, 1000)
ЮТест.Данные().СлучайнаяСтрока(10)       // Строка длиной 10
ЮТест.Данные().СлучайнаяДата()
ЮТест.Данные().СлучайноеБулево()
```

### Подражатель (правдоподобные данные)

```1c
ЮТест.Данные().Подражатель().Имя()
ЮТест.Данные().Подражатель().Фамилия()
ЮТест.Данные().Подражатель().Отчество()
ЮТест.Данные().Подражатель().Компания()
```

### Эмуляция HTTP

```1c
// Создание мок-объекта HTTPСервисЗапрос
Запрос = ЮТест.Данные().HTTPСервисЗапрос()
    .УстановитьТелоКакСтроку('{"id": 123}')
    .УстановитьЗаголовок("Content-Type", "application/json")
    .УстановитьПараметрURL("action", "create")
    .Получить();

// Создание мок-объекта HTTPОтвет
Ответ = ЮТест.Данные().HTTPОтвет()
    .УстановитьКодСостояния(200)
    .УстановитьТело(Новый Структура("success", Истина));
```

**Важно для `HTTPОтвет`:** builder `ЮТест.Данные().HTTPОтвет()` сам является
мок-объектом. У него нет метода `.Получить()`. Для тела ответа используй
`УстановитьТело(Тело)`, а не `УстановитьТелоКакСтроку(...)`.

`УстановитьТелоКакСтроку(...)` и `.Получить()` относятся к примеру
`HTTPСервисЗапрос` выше и не переносятся на `HTTPОтвет`.

### Конструктор XDTO

```1c
Объект = ЮТест.Данные().КонструкторОбъектаXDTO(ТипXDTO)
    .Установить("Свойство", Значение)
    .Получить();
```

## 4. Мокирование (Мокито)

Мокито позволяет подменять поведение методов конфигурации.
Работает через заимствование методов (`&Вместо`).

**Ограничение**: мокирует только методы КОНФИГУРАЦИИ. Не работает для
методов платформы, расширений и внешних обработок.

**Важно:** `Мокито.Обучение(ОбщийМодуль)` не перехватывает вызов само по себе.
В тестовом расширении должен быть заимствованный метод с `&Вместо(...)`,
который вызывает `МокитоПерехват.АнализВызова(...)`. Если такого метода нет,
обучение выглядит корректно, но production-вызов пройдет в исходный метод или
не будет управляться Мокито.

Для типовых и общих модулей перед использованием `Мокито.Обучение(...)`
проверь:

1. В тестовом расширении есть заимствованный общий модуль или заимствованный
   метод владельца.
2. Метод перехватчика помечен `&Вместо("<ИмяМетода>")`.
3. Перехватчик передает тот же набор параметров в `Мокито.МассивПараметров(...)`
   и `ПродолжитьВызов(...)`.
4. Владелец, переданный в `МокитоПерехват.АнализВызова(...)`, совпадает с тем,
   который используется в `Мокито.Обучение(...)`.
5. Контролируемые свойства заимствованного модуля совпадают с исходным модулем:
   сервер, клиент, внешний доступ, серверный вызов и другие флаги EDT metadata.

### Три этапа: Обучение → Прогон → Проверка

```1c
// 1. ОБУЧЕНИЕ — настройка поведения моков
Мокито.Обучение(ВладелецМетода)
    .Когда("ИмяМетода").Вернуть(Значение)        // Вернуть значение
    .Когда("ИмяМетода").ВыброситьИсключение("Текст")  // Выбросить ошибку
    .Когда("ИмяМетода").Пропустить()              // Не выполнять метод
    .Наблюдать("ИмяМетода")                       // Собирать статистику
    .Когда("ИмяМетода").ВыполнитьМетод()          // Выполнить реальный метод
    .Прогон();  // ОБЯЗАТЕЛЬНО завершить обучение!

// 2. ПРОГОН — выполнение тестируемого кода
Результат = ТестируемыйМодуль.ТестируемыйМетод();

// 3. ПРОВЕРКА — анализ вызовов
Мокито.Проверить(ВладелецМетода)
    .КоличествоВызовов("ИмяМетода").Равно(1)
    .КоличествоВызовов("ДругойМетод").Пусто();
```

### Проверка фактических параметров через `.Вызовы()`

Если нужно проверить не только количество вызовов, но и фактические параметры,
используй `Мокито.Проверить(...).Вызовы("ИмяМетода")`. Это особенно полезно
для HTTP-запросов, JSON/XML-тела, динамического URL и других параметров, где
предикат в `КоличествоВызовов()` может скрыть сам факт вызова из-за несовпадения
одного аргумента.

Если мок использует `.Пропустить()` или `.Вернуть(...)` для значимой внешней
границы, проверяй через `.Вызовы()` хотя бы параметры, которые входят в
контракт этой границы. Иначе тест может остаться зеленым после регрессии:
production-код вызовет правильный метод, но передаст неправильный объект,
структуру, URL, HTTP-метод, статус или другой ключевой аргумент.

```1c
ВызовыHTTP = Мокито.Проверить(МодульИнтеграции).Вызовы("ВыполнитьHTTPЗапрос");

ЮТест.ОжидаетЧто(ВызовыHTTP, "Количество HTTP-вызовов")
    .ИмеетДлину(1);

ПараметрыВызова = ВызовыHTTP[0].Параметры;
HTTPМетод = ПараметрыВызова[1];
ПараметрыЗапроса = ПараметрыВызова[3];

ЮТест.ОжидаетЧто(HTTPМетод, "HTTP метод")
    .Равно("PUT");
ЮТест.ОжидаетЧто(ПараметрыЗапроса.ПутьНаСервере, "URL")
    .Равно(СтрШаблон("/api/entity/v1/%1", УИДОбъекта));
ЮТест.ОжидаетЧто(
    ЕШ_СтроковыеФункцииКлиентСервер.УдалитьВсеПробелыИзСтроки(ПараметрыЗапроса.ТелоЗапроса),
    "Тело запроса"
).Равно(ЕШ_СтроковыеФункцииКлиентСервер.УдалитьВсеПробелыИзСтроки(ОжидаемоеТело));
```

`Вызовы()` возвращает массив структур вызовов. У каждой структуры есть поля:

| Поле        | Содержимое                                      |
|-------------|--------------------------------------------------|
| `ИмяМетода` | Имя перехваченного метода                        |
| `Контекст`  | Контекст вызова, для серверного вызова часто `Неопределено` |
| `Объект`    | Мокированный объект                              |
| `Параметры` | Массив фактических параметров, индексация с нуля |

Для `ВыполнитьHTTPЗапрос(HTTPСоединение, Метод, СводнаяНастройка, Параметры, ЕстьОшибки)`:

| Индекс | Значение                                         |
|--------|--------------------------------------------------|
| `[0]`  | HTTP-соединение                                  |
| `[1]`  | HTTP-метод (`"GET"`, `"POST"`, `"PUT"` и т.д.)  |
| `[2]`  | Сводная настройка обмена                         |
| `[3]`  | Параметры запроса: путь, тело, заголовки и т.п.  |
| `[4]`  | Признак ошибки                                   |

Именуй параметры после извлечения из массива (`HTTPМетод`,
`ПараметрыЗапроса`), чтобы тест был читаемым и не превращался в набор
магических индексов.

**Важно:** если для одного и того же объекта нужно настроить несколько методов,
объединяй все `.Когда(...)` в одну цепочку `Мокито.Обучение(...).Когда(...).Когда(...).Прогон()`.
Повторный отдельный вызов `Мокито.Обучение(Объект)` по умолчанию сбрасывает
старые настройки этого объекта (`СброситьСтарыеНастройки = Истина`).

```1c
// ПРАВИЛЬНО: обе реакции обучены одной цепочкой
Мокито.Обучение(МодульИнтеграции)
    .Когда("ИнициализироватьСоединение").Вернуть(МокСоединение)
    .Когда("ОтправитьHTTPЗапрос").Вернуть(МокОтвет)
    .Прогон();

// НЕПРАВИЛЬНО: второй вызов Обучение может сбросить первую реакцию
Мокито.Обучение(МодульИнтеграции)
    .Когда("ИнициализироватьСоединение").Вернуть(МокСоединение)
    .Прогон();

Мокито.Обучение(МодульИнтеграции)
    .Когда("ОтправитьHTTPЗапрос").Вернуть(МокОтвет)
    .Прогон();
```

### Условия по параметрам

```1c
// Мокирование с конкретными параметрами
Мокито.Обучение(Модуль)
    .Когда("Метод", Мокито.МассивПараметров(Параметр1, Параметр2))
    .Вернуть(Результат)

// Любой параметр
    .Когда("Метод", Мокито.МассивПараметров(Мокито.ЛюбойПараметр(), Конкретный))
    .Вернуть(Результат)

// Условие через предикат
    .Когда("Метод", Мокито.МассивПараметров(
        ЮТест.Предикат().Содержит("example.com").Получить()))
    .Вернуть(Результат)
```

**Важно**: при использовании нескольких предикатов в одном `МассивПараметров`
завершай каждый предикат вызовом `.Получить()`.

### Цепочка возвращаемых значений

```1c
Мокито.Обучение(Модуль)
    .Когда("Метод")
    .Вернуть(1)    // Первый вызов → 1
    .Вернуть(2)    // Второй вызов → 2
    .Вернуть(3)    // Третий и далее → 3
    .Прогон();
```

### Мокирование по умолчанию + исключения для конкретных параметров

```1c
Мокито.Обучение(Модуль)
    // По умолчанию — выбросить исключение
    .Когда("ВыполнитьЗапрос").ВыброситьИсключение("Некорректный вызов")
    // Для конкретного параметра — выполнить реальный метод
    .Когда("ВыполнитьЗапрос", Мокито.МассивПараметров(КорректныйПараметр))
        .ВыполнитьМетод()
    .Прогон();
```

## 5. Предикаты

Предикаты — набор условий для фильтрации и проверки значений.
Точка входа: `ЮТест.Предикат()`.

```1c
// Простой предикат
ЮТест.Предикат()
    .ИмеетТип("Число")
    .Больше(0)
    .МеньшеИлиРавно(100)

// Предикат с проверкой реквизитов
ЮТест.Предикат()
    .Реквизит("ВидДвижения").Равно(ВидДвиженияНакопления.Приход)
    .Реквизит("Количество").Больше(0)
    .Реквизит("Номенклатура").Заполнено()

// Использование в утверждениях для коллекций
ЮТест.ОжидаетЧто(Движения)
    .КаждыйЭлементСоответствуетПредикату(
        ЮТест.Предикат()
            .Реквизит("ВидДвижения").Равно(ВидДвиженияНакопления.Приход)
            .Реквизит("Количество").Больше(0))

// Если предикат используется в МассивПараметров — завершай .Получить()
УсловиеПараметра = ЮТест.Предикат()
    .ИмеетТип("Строка")
    .Содержит("test")
    .Получить();
```

### Доступные методы предикатов

Предикат поддерживает все те же проверки, что и утверждения: `Равно`, `НеРавно`,
`Больше`, `Меньше`, `Заполнено`, `НеЗаполнено`, `Содержит`, `НеСодержит`,
`ИмеетТип`, `НачинаетсяС`, `ЗаканчиваетсяНа`, `ИмеетДлину` и т.д.
Для доступа к вложенным реквизитам — `.Реквизит("ИмяРеквизита")`.

## 9. Шаблоны заимствованных методов для Мокито

Чтобы мокировать метод, нужно добавить заимствованный метод в расширение.
Ниже шаблоны.

Для общего модуля сначала создай или проверь заимствованный общий модуль в
тестовом расширении. Его свойства должны соответствовать исходному модулю.
В EDT это особенно важно для флагов доступности по контекстам выполнения:
сервер, клиент, внешнее соединение, серверный вызов и аналогичные
контролируемые свойства. Не копируй только текст метода без проверки metadata
модуля.

### Для функции

```1c
&Вместо("<ИмяМетода>")
Функция Мок_<ИмяМетода>(<ПараметрыМетода>)
    ПараметрыМетода = Мокито.МассивПараметров(<ПараметрыМетода>);
    ПрерватьВыполнение = Ложь;
    Результат = МокитоПерехват.АнализВызова(<Объект>, "<ИмяМетода>",
        ПараметрыМетода, ПрерватьВыполнение);
    Если Не ПрерватьВыполнение Тогда
        Возврат ПродолжитьВызов(<ПараметрыМетода>);
    Иначе
        Возврат Результат;
    КонецЕсли;
КонецФункции
```

### Для процедуры

```1c
&Вместо("<ИмяМетода>")
Процедура Мок_<ИмяМетода>(<ПараметрыМетода>)
    ПараметрыМетода = Мокито.МассивПараметров(<ПараметрыМетода>);
    ПрерватьВыполнение = Ложь;
    МокитоПерехват.АнализВызова(<Объект>, "<ИмяМетода>",
        ПараметрыМетода, ПрерватьВыполнение);
    Если Не ПрерватьВыполнение Тогда
        ПродолжитьВызов(<ПараметрыМетода>);
    КонецЕсли;
КонецПроцедуры
```

### Правила подстановки `<Объект>`

| Тип модуля | Что подставлять | Пример |
|------------|-----------------|--------|
| Общий модуль | Ссылка на модуль | `ОбщегоНазначения` |
| Модуль менеджера | Ссылка на менеджер | `Справочники.Пользователи` |
| Модуль объекта | `ЭтотОбъект` | `ЭтотОбъект` |

### Пример 3: Тесты проведения документа с проверкой движений

Для прикладных объектов с собственным префиксом в имени объекта этот префикс
сохраняется в имени тестового модуля:

```1c
// Тестовый модуль: Док_ЗаказПокупателя_МО
// Тестируемый объект: Документ.ЗаказПокупателя
```

Используй кириллические префиксы ровно по соглашению. Латинские варианты
`Dok_`, `Doc_`, `Spr_`, `Obr_` недопустимы.

```1c
// Тестовый модуль: Док_ПриходТовара_МО
// Тестируемый объект: Документ.ПриходТовара

Процедура ИсполняемыеСценарии() Экспорт

    ЮТТесты
        .ВТранзакции()
        .Перед("ПодготовкаОкружения")

        .ДобавитьТестовыйНабор("Проведение")
            .ДобавитьСерверныйТест("Проведение_ФормируетДвиженияПоОстаткам")
            .ДобавитьСерверныйТест("Проведение_БезСтрок_НеФормируетДвижения")
            .ДобавитьСерверныйТест("Проведение_БезДаты_ВыбрасываетИсключение")

        .ДобавитьТестовыйНабор("Отмена проведения")
            .ДобавитьСерверныйТест("ОтменаПроведения_УдаляетДвижения")
    ;

КонецПроцедуры

Процедура ПодготовкаОкружения() Экспорт

    Товар1 = ЮТест.Данные().КонструкторОбъекта("Справочники.Номенклатура")
        .Установить("Наименование", "Тестовый товар 1")
        .Записать();

    Товар2 = ЮТест.Данные().КонструкторОбъекта("Справочники.Номенклатура")
        .Установить("Наименование", "Тестовый товар 2")
        .Записать();

    Склад = ЮТест.Данные().СоздатьЭлемент("Справочники.Склады");
    Поставщик = ЮТест.Данные().СоздатьЭлемент("Справочники.Контрагенты");

    ЮТест.Контекст().Установить("Товар1", Товар1);
    ЮТест.Контекст().Установить("Товар2", Товар2);
    ЮТест.Контекст().Установить("Склад", Склад);
    ЮТест.Контекст().Установить("Поставщик", Поставщик);

КонецПроцедуры

Процедура Проведение_ФормируетДвиженияПоОстаткам() Экспорт

    // Подготовка
    Товар1 = ЮТест.Контекст().Получить("Товар1");
    Товар2 = ЮТест.Контекст().Получить("Товар2");
    Склад = ЮТест.Контекст().Получить("Склад");
    Поставщик = ЮТест.Контекст().Получить("Поставщик");

    Ссылка = ЮТест.Данные().КонструкторОбъекта("Документы.ПриходТовара")
        .Установить("Дата", ТекущаяДата())
        .Установить("Поставщик", Поставщик)
        .Установить("Склад", Склад)
        .ДобавитьСтроку("Товары")
            .Установить("Товар", Товар1)
            .Установить("Количество", 10)
            .Установить("Цена", 100)
        .ДобавитьСтроку("Товары")
            .Установить("Товар", Товар2)
            .Установить("Количество", 5)
            .Установить("Цена", 200)
        .Провести();

    // Проверка движений
    Движения = ЮТЗапросы.ДвиженияДокумента(Ссылка, "ОстаткиТоваров");

    ЮТест.ОжидаетЧто(Движения, "Движения по остаткам")
        .Заполнено()
        .ИмеетДлину(2)
        .КаждыйЭлементСоответствуетПредикату(
            ЮТест.Предикат()
                .Реквизит("ВидДвижения").Равно(ВидДвиженияНакопления.Приход)
                .Реквизит("Количество").Больше(0)
                .Реквизит("Склад").Равно(Склад))
        .Содержит(
            ЮТест.Предикат()
                .Реквизит("Номенклатура").Равно(Товар1)
                .Реквизит("Количество").Равно(10))
        .Содержит(
            ЮТест.Предикат()
                .Реквизит("Номенклатура").Равно(Товар2)
                .Реквизит("Количество").Равно(5));

КонецПроцедуры

Процедура Проведение_БезСтрок_НеФормируетДвижения() Экспорт

    // Подготовка — документ без строк
    Поставщик = ЮТест.Контекст().Получить("Поставщик");
    Склад = ЮТест.Контекст().Получить("Склад");

    Ссылка = ЮТест.Данные().КонструкторОбъекта("Документы.ПриходТовара")
        .Установить("Дата", ТекущаяДата())
        .Установить("Поставщик", Поставщик)
        .Установить("Склад", Склад)
        .Провести();

    // Проверка — движений нет
    Движения = ЮТЗапросы.ДвиженияДокумента(Ссылка, "ОстаткиТоваров");

    ЮТест.ОжидаетЧто(Движения, "Движения пустого документа")
        .НеЗаполнено();

КонецПроцедуры

Процедура Проведение_БезДаты_ВыбрасываетИсключение() Экспорт

    // Подготовка — документ без даты
    Поставщик = ЮТест.Контекст().Получить("Поставщик");

    Документ = Документы.ПриходТовара.СоздатьДокумент();
    Документ.Поставщик = Поставщик;

    // Проверка — исключение при проведении
    ЮТест.ОжидаетЧто(Документ)
        .Метод("Записать").Параметр(РежимЗаписиДокумента.Проведение)
        .ВыбрасываетИсключение("Дата");

КонецПроцедуры

Процедура ОтменаПроведения_УдаляетДвижения() Экспорт

    // Подготовка — проведённый документ
    Товар = ЮТест.Контекст().Получить("Товар1");
    Склад = ЮТест.Контекст().Получить("Склад");
    Поставщик = ЮТест.Контекст().Получить("Поставщик");

    Ссылка = ЮТест.Данные().КонструкторОбъекта("Документы.ПриходТовара")
        .Установить("Дата", ТекущаяДата())
        .Установить("Поставщик", Поставщик)
        .Установить("Склад", Склад)
        .ДобавитьСтроку("Товары")
            .Установить("Товар", Товар)
            .Установить("Количество", 10)
            .Установить("Цена", 100)
        .Провести();

    // Действие — отмена проведения
    ДокОбъект = Ссылка.ПолучитьОбъект();
    ДокОбъект.Записать(РежимЗаписиДокумента.ОтменаПроведения);

    // Проверка — движения удалены
    Движения = ЮТЗапросы.ДвиженияДокумента(Ссылка, "ОстаткиТоваров");

    ЮТест.ОжидаетЧто(Движения, "Движения после отмены проведения")
        .НеЗаполнено();

КонецПроцедуры
```
