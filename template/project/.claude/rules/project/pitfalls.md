# Project Pitfalls

Этот файл — project-specific база известных ловушек проекта. Добавляй сюда
только устойчивые правила, которые пригодятся в будущих задачах.

## Когда обновлять

- После закрытия feedback или review, если замечание выявило устойчивую
  проектную особенность.
- После расследования ошибки, если причина может повториться.

## Что не добавлять

- Одноразовые детали конкретного тикета.
- Временные решения без подтверждения.
- Общие правила, которые должны жить в `~/.claude/rules/core`.
