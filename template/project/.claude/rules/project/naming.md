# Naming Rules

Этот файл — project-specific source of truth по именованию метаданных, модулей,
реквизитов, команд, форм и тестовых артефактов.

## Общие правила

- Новые имена должны сохранять смысловую формулировку задачи и PRD.
- Не сокращай смысловые части имени без явно зафиксированного решения
  пользователя.
- Если задача говорит "переименовать", по умолчанию меняется техническое имя
  метаданных и связанные ссылки, а не только синоним или заголовок.
