# Path Rules

Эта директория содержит project-specific path-scoped rules.

Создавай отдельный файл на каждую значимую зону репозитория:

- рабочие исходники;
- расширения;
- тестовые артефакты;
- внешние обработки или отчеты;
- readonly или generated-зоны.

Для нового проекта скопируй `source-example.md`, переименуй его под реальный
путь и заполни `paths` в frontmatter.
