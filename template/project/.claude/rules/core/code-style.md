# Code style for 1C

Стиль кода 1С задан корпоративным стандартом
[`bsl-style.md`](../../../doc/ai/standards/bsl-style.md): соответствие
окружающему коду, именование и запрет смысловых сокращений, структура и размер
метода, читаемость и `СтрШаблон`, документирующие комментарии EDT для экспортных
методов, отсутствие комментариев внутри процедур по умолчанию, запрет
закомментированного мёртвого кода, комментарии-обёртки в вендорском коде и
граница ответственности `bsl-language-server`.

Здесь только то, чего в стандарте нет.

## Дельта личного слоя

- Используй CamelCase для имён объектов и переменных, если более узкое правило
  для конкретного артефакта не говорит иначе.
- Комментарии сверх того, что разрешает стандарт, добавляй только по прямому
  указанию пользователя.
- Project-specific правила именования из `.claude/rules/project/naming.md` и
  path rules имеют приоритет над этим файлом и над стандартом в части, которую
  проект подтвердил явно.
